# Step 12 — Debugging Project Structure

## Problem

FastAPI failed with:

```
Could not import module "app.main"
```

## Cause

An accidental nested directory:

```
app/
    app/
```

had been created.

## Resolution

Moved:

```
main.py
```

to the correct location.

Created:

```
__init__.py
```

Removed the extra folder.

Lesson learned:

Python package structure is critical for imports.
